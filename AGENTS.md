# Portfolio Repository Instructions

These instructions apply to the entire repository.

## Preserve the existing website

1. Keep the existing burgundy, cream, and white design.
2. Do not change fonts, layout, animations, or colors without the owner's approval.

## Implementation and quality

3. Use semantic HTML5, external CSS, and JavaScript.
4. Keep the website responsive on phones and laptops.
5. Keep every image under 500 KB.
6. Maintain a Lighthouse Accessibility score of at least 90 on every page.
7. Make sure all interactive elements support keyboard navigation and have visible focus states.
8. Do not add unnecessary libraries or frameworks.

## Workflow

9. Make small changes, one task at a time.
10. Explain every change before committing.
11. Test changes before committing and before pushing to GitHub. Check responsive behavior, keyboard navigation, and accessibility on affected pages. Report any checks that could not be completed.
12. Never use reset or force push to undo changes.

## Assignment requirements: five pages

The assignment requires the following five pages:

- **Home:** Introduce Jana and provide navigation to the rest of the portfolio.
- **About Me:** Describe Jana's interests and background using only information she approves for sharing.
- **Projects:** Present project examples with descriptions, relevant images, and working links or demos when available.
- **Skills:** Present relevant technical and design skills clearly and accurately.
- **Contact:** Provide approved contact information and working contact or professional-profile links.

Keep navigation clear and consistent across all five. Do not remove existing content or restructure the website to meet these requirements without approval.
